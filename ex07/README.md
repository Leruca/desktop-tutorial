# Ex 07 - Web Slider Dimmer

ESP32 creates a Wi-Fi hotspot and serves a webpage with a brightness slider.

## Use

1. Upload `ex07.ino`.
2. Connect phone or computer Wi-Fi to `ESP32-Dimmer`.
3. Password: `12345678`.
4. Open `http://192.168.4.1`.
5. Drag the slider and watch the LED brightness change.

## Pin

- LED: GPIO 2
