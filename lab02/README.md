# Lab 02 - Basic GPIO LED Blink

This sketch completes the LED blink task from lab02.

## Hardware

- ESP32 development board
- Built-in LED on GPIO 2
- USB cable

## Behavior

The LED turns on for 1 second, turns off for 1 second, and repeats.

## Upload

1. Open `lab02.ino` in Arduino IDE.
2. Select `ESP32 Dev Module`.
3. Select the correct COM port.
4. Upload and open Serial Monitor at `115200`.
